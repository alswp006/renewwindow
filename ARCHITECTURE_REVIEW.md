# Architecture Review
Generated: 2026-10-05T17:46:27.012Z
Score: 62/100

## Summary
The app has a clear layered layout (pages → components → hooks → lib → constants), a pure and well-tested domain layer (date, money, renewal, notice) and consistent Korean-language docs. Structural quality is weakened by heavy copy-paste of SDK-guard helpers (haptics ×8, quota handling ×2, impression logging ×4), a direct circular import between renewal.ts and notice.ts, and several apparently unused template components and a stale generated contract.ts that contradicts types.ts. Import style, quote style, test locations, and result/error-handling conventions are also mixed.
