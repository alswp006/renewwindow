# RenewWindow
앱 이름: 갱신체크 / RenewWindow

## Platform
앱인토스 (Vite + React + TDS)

## One-liner
전세·월세 만기 앞두고 있다면? 갱신 요구할 수 있는 날짜와 올릴 수 있는 최대 금액을 한 번에

## Problem
세입자는 계약 만기 6개월 전부터 2개월 전까지 갱신을 요구할 수 있지만, 정확한 날짜를 직접 세는 사람은 드뭅니다. 집주인이 인상을 통보했을 때 5% 상한이 맞는지, 월세로 바꾸면 얼마까지 가능한지도 감으로 협상하게 됩니다. 지금은 메모나 검색, 지인 조언에 의존합니다.

## Target Users
전월세 거주 중인 20~40대 세입자, 특히 만기가 1년 안에 있는 사람

## Core Features
1. 계약 만기일 입력 시 갱신 요구 가능 기간의 시작일과 마감일을 D-day로 표시
2. 현재 보증금·월세를 넣으면 5% 상한 기준 최대 인상 금액을 계산
3. 보증금 일부를 월세로 바꿀 때의 법정 전환율 상한 기준 월세 시뮬레이션
4. 집주인 통보 내용(인상률·통보일)을 넣어 상한 초과 여부 점검
5. 계약을 여러 건 등록하고 가장 가까운 창구 순으로 정렬

## Goal
이 앱을 쓰고 나면 사용자는 집주인에게 5% 상한을 근거로 인상 수정을 요구하거나, 갱신 요구 통보를 마감일 전에 보낸다.

## User Payoff
- 매번 얻는 결과물: 내 계약의 갱신 요구 가능 기간 타임라인과 상한 적용 후 보증금·월세 금액 카드
- 앱이 더하는 것: 법에서 정한 갱신 요구 기간 날짜 계산, 5% 상한 적용, 법정 전환율 상한 기준 월세 환산. 사용자가 모르는 날짜와 금액을 계산해 줍니다.

## Monetization
- Model: ads
- Estimated MRR: 월 2,305원(출시 직후 DAU 15 기준, 리워드 시청 전환율 0.2 가정)
- Reasoning: 핵심 답인 갱신 가능 기간과 5% 상한 금액은 무료로 둡니다. 월세 전환 시나리오 비교와 협상 시 확인할 체크리스트는 리워드 광고 뒤에 둡니다. 외부 채널 없이는 DAU 10~15명 기저선을 가정했고, 만기 시즌에 검색 유입이 생기면 달라질 수 있습니다.
- Estimated DAU: 15
- Monthly Net Revenue (KRW): 2305
